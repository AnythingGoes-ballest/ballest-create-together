# Create Together

Edit one Ballest map with friends.

- **create together** in the Create menu: open sessions (public ones and your friends'), join one with its code, or
  start your own from a new map or one of your saved maps. Choose who can join (everyone's list, friends, anyone with
  the code, Steam invites only) and how many players.
- In the editor: a **together** tab (the code, who's there, Steam invites, leave) and a badge at the top.
- The host owns the map: only the host can save or publish it. When the host leaves, the session ends; anyone else can
  leave and come back.
- Everyone's undo and redo are their own.
- It runs on the editor's own networking over Steam (Steam's relay, no open ports). Requires the plugin manager host
  0.34.0.
